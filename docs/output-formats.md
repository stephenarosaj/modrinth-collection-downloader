# Output Formats

All exports are pure projections of the in-memory `Instance` ([`src/core/model.ts`](../src/core/model.ts)) via [`src/core/projections.ts`](../src/core/projections.ts) and [`src/core/serialize.ts`](../src/core/serialize.ts), orchestrated in the browser by [`src/ui/download.ts`](../src/ui/download.ts).

---

## 1. Environment Zip Archives (`<collectionId>-client.zip` & `<collectionId>-server.zip`)

- **Gating:** **Export client.zip** / **Export server.zip** requires that environment's top-level toggle to be **on** and ≥1 exportable entry (`mod`, `plugin`, `datapack`, `resourcepack`, `shader`) selected (`selection.on === true` and `version !== null`) in that environment.
- **On-Demand Fetching & Partial-Failure Packaging:** Binaries are downloaded from `VersionRef.file.url` only at export time with live progress and `AbortSignal` cancellation. If a subset of downloads fail while ≥1 succeeds, all succeeded files are still packaged and downloaded into `<collectionId>-<env>.zip`, and failed files are returned for display and **Retry export**. If 100% of downloads fail, no empty `.zip` is downloaded.

### Folder Layout & Deterministic File Naming (`src/core/naming.ts`)

| Project Type | Zip Folder | Filename Pattern | Example |
| :--- | :--- | :--- | :--- |
| `mod` | `mods/` | `{Title}-{Platform}-{GameVersion}-{VersionNumber}.{ext}` | `BetterThirdPerson-Forge-1.20.1-1.9.0.jar` |
| `plugin` | `plugins/` | `{Title}-{Platform}-{GameVersion}-{VersionNumber}.{ext}` | `WorldGuard-Paper-1.20.1-7.0.9.jar` |
| `datapack` | `datapacks/` | `{Title}-{GameVersion}-{VersionNumber}.{ext}` | `Terralith-1.20.1-2.5.4.zip` |
| `resourcepack` | `resourcepacks/` | `{Title}-{GameVersion}-{VersionNumber}.{ext}` | `FreshAnimations-1.20.1-1.9.2.zip` |
| `shader` | `shaderpacks/` | `{Title}-{GameVersion}-{VersionNumber}.{ext}` | `ComplementaryUnbound-1.20.1-r5.2.2.zip` |

- **`{Title}` (`formatTitle`):** Split `project.title` on whitespace, strip non-ASCII-alphanumeric (`[^A-Za-z0-9]`), upper-case the first letter of each word, and join without separators (falls back to `project.slug`, `project.id`, then `"Project"`).
- **`{Platform}` (`formatPlatformDisplayName`):** Canonical display name (`Fabric`, `Forge`, `NeoForge`, `Quilt`, `Paper`, `Purpur`, `Spigot`, `Bukkit`, `Folia`, `Velocity`, `BungeeCord`, `Sponge`; title-case fallback). Omitted for platform-agnostic types.
- **`{GameVersion}` & `{VersionNumber}` (`sanitizeVersionNumber`):** Reserved filesystem characters `\ / : * ? " < > |` and whitespace replaced with `-`.
- **Collision Suffixing (`resolveUniqueFilename`):** Tracked per folder. Duplicate base filenames in the same folder append `-2`, `-3`, … before `.{ext}` (`ExampleMod-Fabric-1.20.1-1.0.0-2.jar`).

## 2. Portable Instance JSON (`<collectionId>-instance.json`)

- **Schema & Types:** Authoritative JSON Schema (Draft 2020-12, `additionalProperties: false`) lives in [`schema/instance.schema.json`](../schema/instance.schema.json), matching `Instance` (`schemaVersion: 1`) in [`src/core/model.ts`](../src/core/model.ts).
- **Invariants (`src/core/serialize.ts`):**
  - **Lossless Round-Trip:** `serialize(deserialize(json)) === json` with deterministic key ordering and 2-space indentation.
  - **No Derived State or Binaries:** `Status` is never stored in `instance.json`; `VersionRef.file` stores only CDN metadata (`filename`, `url`, `size`, `sha1`, `sha512`).
  - **Zero-Network Offline Import:** Importing `instance.json` validates against `schema/instance.schema.json`, rejects unknown `schemaVersion` values (`Unsupported schemaVersion "<v>": only schemaVersion 1 is supported.`), syncs the target form, resets top-level **Client**/**Server** toggles to **off**, and restores all tables, candidates, dependencies, and selections with zero HTTP requests.

## 3. Modrinth Modpack (`<collectionId>.mrpack`)

Generated by `toMrpack(instance, { platformVersion })` as a ZIP archive containing `modrinth.index.json` (`formatVersion: 1`) with zero binary downloads.

- **Included vs. Excluded Types:**
  - `mod` (`mods/`), `resourcepack` (`resourcepacks/`), `shader` (`shaderpacks/`), and `datapack` (`datapacks/`) are included in `files[]` using the deterministic filename convention above.
  - **Datapack Path Note:** Launchers (Modrinth App, Prism Launcher) extract `datapacks/<filename>` to `<instance_root>/datapacks/<filename>`, which requires either a global datapack loader mod (e.g., Paxi, Global Packs) or copying into `saves/<world>/datapacks/` for vanilla per-world loading.
  - **Plugin Exclusion Warning:** `.mrpack` does not support server plugins. `toMrpack` excludes `plugin` entries, and `getMrpackWarnings(instance)` emits a warning listing any selected plugins excluded from the archive.
- **Environment Mapping (`files[].env`):**
  - Selected cell (`selection.on && support !== 'unsupported' && version !== null`): `'required'` → `"required"`, `'optional'` or `'unknown'` → `"optional"`.
  - Unselected or unsupported cell: `"unsupported"`.
  - **Same vs. Split Versions:** If `client` and `server` select the same `version.id` (or only one environment is selected), emits **1** `files[]` entry. If `client` and `server` select **different** `version.id`s of the same project, emits **2** `files[]` entries (`{ client: <env>, server: "unsupported" }` and `{ client: "unsupported", server: <env> }`, deduplicating colliding filenames with `-2`).
- **Root `dependencies` & Optional Platform Version:**
  - Always writes `"minecraft": "<gameVersion>"`.
  - When a non-empty `platformVersion` is provided and `meta.target.platform` maps to a supported `.mrpack` loader key (`fabric` → `"fabric-loader"`, `quilt` → `"quilt-loader"`, `forge` → `"forge"`, `neoforge` → `"neoforge"`), adds `<loaderKey>: "<platformVersion>"`. When blank or on other platforms, writes only `"minecraft"`.
